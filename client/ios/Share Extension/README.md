# iOS Share Extension Setup

The Flutter client already consumes incoming share events through
`receive_sharing_intent`. iOS requires an additional native Share Extension target in
Xcode; this cannot be generated by `flutter create` alone.

1. Open `ios/Runner.xcworkspace` in Xcode.
2. Add a **Share Extension** target named `Share Extension`.
3. Set the deployment target to iOS 13 or newer for both Runner and the extension.
4. Add the App Groups capability to both targets and create:
   `group.com.xaprier.xownloader`.
5. Add the same `CUSTOM_GROUP_ID` user-defined build setting to both targets with the
   value `group.com.xaprier.xownloader`.
6. Add `receive-sharing-intent` from the Swift package to the Share Extension target.
7. Make the extension controller inherit from `RSIShareViewController`:

```swift
import receive_sharing_intent

class ShareViewController: RSIShareViewController {
    override func shouldAutoRedirect() -> Bool { true }
}
```

8. Configure the extension activation rule for one web URL and one text item.
9. Add the App Group and `ShareMedia-$(PRODUCT_BUNDLE_IDENTIFIER)` URL scheme to
   Runner’s capabilities and `Info.plist` as required by the plugin.
10. Test both cold-start and already-running share flows on a physical iOS device.

The extension opens Xownloader with the shared URL. The Flutter app puts it into the
URL field and starts metadata preview; it never starts a download automatically.
